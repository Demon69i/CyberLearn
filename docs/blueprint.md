# **App Name**: CyberLearn

## Core Features:

- User Authentication: User login and authentication using NextAuth.
- Course Catalog: Browse and search through the Cyber Security and Ethical Hacking courses.
- Course Content Display: View detailed course content including embedded YouTube video lessons.
- Course Recommendation: Manually include links to related courses based on viewing history, skill level and selected topics.

## Style Guidelines:

- Primary color: Electric Blue (#7DF9FF) to evoke technology and security.
- Background color: Dark blue-gray (#2B3035), desaturated to 20%, to provide a professional, low-glare feel.
- Accent color: Cyber yellow (#BFFF00), analogous to blue but with significant brightness and saturation difference.
- Body and headline font: 'Inter' sans-serif for a modern, clean look.
- Use outline icons related to cyber security, such as padlocks, shields, and network symbols.
- Subtle transitions and loading animations to enhance user experience.
